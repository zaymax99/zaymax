## Apple Health steps

Open **Steps**, start the Apple Health connection and allow read access to **Steps**. If no data appears, check Health access for ZAYMAX in the Health app or iOS privacy settings, then reopen ZAYMAX. HealthKit requires a real iPhone and is not available in browser previews. All core features work without Health access.

## Lock Screen note widget

Select a diary note with **Show in Lock Screen widget**. Then press and hold the iPhone Lock Screen, choose **Customize**, open the widget area and add the ZAYMAX note widget. If it is missing, install ZAYMAX 1.0.2 or later, open the app once and restart the iPhone. Avoid confidential text because widget content can be visible on the Lock Screen.

## Backup before reinstalling

Open **Settings**, export a local backup and save the JSON file outside ZAYMAX through the iOS share sheet. Verify the file before deleting or reinstalling the app. Restore it with the import function in Settings. The backup is not encrypted and may contain personal data. Without a backup, the developer cannot recover locally deleted data.

## First troubleshooting steps

- Fully close and reopen ZAYMAX.
- Check the App Store for an update.
- Restart the iPhone.
- Check the relevant iOS Health or notification permission.
